# Planning Center logo (required for the sign-in button)

Planning Center's brand guidelines require their official, unmodified logo, so this project doesn't
include a drawn version.

1. Download the official logo package from https://www.planningcenter.com/logos
   (direct link: https://planningcenterassets.s3.amazonaws.com/downloads/Planning_Center_Logos--V1.0.3.zip).
2. From the package, take the full-colour Planning Center **icon / logomark** as an SVG.
3. Save it here as `planning-center-icon.svg`. Don't edit, recolour or crop it.

Until the file is here, the button shows the words "Sign in with Planning Center" with no logo.
